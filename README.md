# Los Horizon

A browser-based, original open-world driving prototype inspired by cinematic city racing and pursuit gameplay.

## Features

- 3D city grid with road loops and buildings
- Drivable player car with arcade handling
- Keyboard driving controls
- Dynamic HUD for speed, wanted level, score, and multiplier
- Police-style chase escalation based on speed and drift
- Traffic NPC cars
- Day/night lighting cycle
- Overview camera and chase camera feel
- GitHub Pages deployment workflow

## Controls

- W / S: accelerate / brake
- A / D: steer
- Space: handbrake
- Shift: boost / drift assist
- R: reset vehicle position

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy

The repository includes a GitHub Actions workflow for GitHub Pages deployment.
